# v0.72 省略主语短句回归

测试日期：2026-09-27

## 测试范围

本轮选取 60 条短输入，覆盖：

- 省略主语的行动陈述，如“今天休息”“今天去跑步”；
- 极短的否定或边界表达，如“不去了”“我不吃了”“不想说话”；
- “我该……”行动问句；
- 单纯情绪、事实问句、二选一、自我价值、自伤和伤害他人表达。

每条通过本地服务提交 2 次，共 120 次真实 Jev 联动请求。

## 修改前结果

- 请求错误：0 / 120
- 路线不一致：1 条输入
- 严格路线偏差：6 条输入（按每次请求计 11 次）

稳定偏差主要来自明确行动短句被 proposalClarity 保守拦截：

- “今天休息”
- “今天去跑步”
- “我该留下吗”

另外，“不去了”“我不吃了”“不想说话”缺少具体对象或带有情绪/边界歧义，不宜直接当成清晰议案；“不想动”在 emotion 与 unclear 之间出现过一次模型波动。

## v0.72 修改

- `我该……吗` 纳入个人行动问句的结构兜底，同时继续排除他人主体的事实问句。
- 支持“今天/今晚/明天/现在/周末/先/暂时/以后 + 明确行动”的省略主语短句；仅在句法能读出行动方向时触发，不新增活动名称词表。
- 结构兜底确认个人行动后，允许其覆盖一次不稳定的 `proposalClarity=missing`，但仍保留“去/做/买”等无对象泛化方向的 `unclear` 保护。

## 修改后定向复测

以下 6 条各提交 5 次：

- “今天休息”：5 / 5 进入议案；
- “今天去跑步”：5 / 5 进入议案；
- “我该留下吗”：5 / 5 进入议案；
- “不去了”：5 / 5 `invalid:unclear`；
- “不想说话”：5 / 5 `invalid:unclear`；
- “我不吃了”：5 / 5 `invalid:unclear`。

## 修改后批量复跑

同一组 60 条再次提交 2 次，共 120 次：

- 请求错误：0 / 120
- 路线不一致：1 条输入（“不想动”，一次 emotion、一次 unclear）
- 稳定的保守差异：3 条输入（“不去了”“我不吃了”“不想说话”）
- 新增结构兜底覆盖的 3 条明确行动均稳定进入议案。

这些保守差异都没有启动投票，不会产生错误的三角色裁决；它们保留为下一轮“短句情绪与边界”的专项观察项，不继续堆叠单词规则。
