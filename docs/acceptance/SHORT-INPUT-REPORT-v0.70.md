# v0.70 冲突意愿与单一行动回归

测试日期：2026-09-27

## v0.69 冲突样本

使用 20 组“明确行动 + 相反顾虑/外部压力”的输入，每组 3 种表达，共 60 次真实 Jev 请求：

- 请求错误：0 / 60
- 入口路线差异：1 / 20 组
- 自我票差异：2 / 20 组
- 最终结果差异：7 / 20 组

大多数最终结果差异来自真实的意愿冲突，例如“想见但害怕”“想拒绝但怕得罪人”；它们并不一定应被强行统一。唯一明确的入口误判是：

`我想下班休息，但工作没做完，我要继续加班吗`

这是一项“是否继续加班”的单一行动，前半句是顾虑，不是第二个议案，却曾被路由为 `multiple`。

## v0.70 修改与复核

结构兜底现在识别“我要/我还要继续某行动吗”，并在没有“还是/或者”等真正多选结构时，将前后顾虑保持为一个议案。

定向复核：

- `我想下班休息，但工作没做完，我要继续加班吗`：5 / 5 稳定进入议案，三票全否；
- `我想买电脑还是换手机`：3 / 3 稳定返回 `invalid:multiple`；
- `我想买电脑也想换手机`：3 / 3 稳定返回 `invalid:multiple`。
