# v0.58 短句稳定性回归

测试日期：2026-09-27

## 测试方法

- 使用真实 Jev，通过本地 `/api/decide` 联动测试。
- 20 条全新短句，每条连续提交 3 次，共 60 次请求。
- 覆盖明确议案、情绪、事实、二选一、自我价值、危机和无对象输入。
- 检查入口路线、路线重复稳定性、三角色票型和最终通过/否决结果。

## 结果

- 请求错误：0 / 60。
- 入口路线误判：0 / 60。
- 同一句话路线变化：0 / 20。
- 同一句话票型变化：0 / 20。
- 同一句话最终结果变化：0 / 20。

代表性样本：

- `我今天早退可以吗`：稳定进入议案，三票通过。
- `明早请一天假吗`：稳定进入议案，三票通过。
- `周末见朋友吗`：稳定进入议案，三票否决。
- `要不要继续`、`怎么办`：稳定返回含义不明，不进入投票。
- `心情很差`：稳定返回情绪，不进入投票。
- `他是不是骗我`：稳定返回事实，不进入投票。
- `先吃饭还是先洗澡`：稳定返回多选，不进入投票。
- `我值得吗`：稳定进入自我价值照护。
- `不想醒来`：稳定进入危机照护。

v0.58 的对象清晰度门槛和“用户下一步行动问句”语义补强均通过这轮盲测。该版本尚未冻结，后续仍需决定是否扩大短句样本后再建立新的冻结基线。
