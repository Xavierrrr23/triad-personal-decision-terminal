# v0.64 角色投票稳定性回归

## v0.63 批量结果

使用 60 条已确认可以作为议案的输入，每条提交 2 次，共 120 次真实 Jev 请求，覆盖普通生活、财务风险、深夜活动、紧急事项、社交压力和关系边界。

- 请求错误：0 / 120
- 路由偏差：6 / 120
- 路线变化：2 / 60
- 角色票型变化：3 / 60
- 最终结果变化：3 / 60

其中两个路由偏差是测试标注过宽：`买完它我就交不起房租了，但我还是想买` 和 `我想买很贵的东西` 都没有唯一购买对象，稳定返回 `invalid:unclear` 更符合对象清晰度规则。

真正需要处理的边界是：

- `他威胁我，但我今晚要不要去见他`：一次进入危机照护，另一次进入议案；
- `父母反对，但我还要结婚吗`：自我角色一票波动，导致最终结果变化；
- `周末我想去旅行`：一次入口异常，另一次正常议案。

## v0.64 修改与复核

- 威胁、骚扰或过去家暴作为外部压力背景时，优先由 `pressureContext=coercion_or_threat` 交给守护角色保护；只有明确说明危险正在发生或即将发生，才升级 `immediate_danger`；
- 自我角色在原文只有父母、朋友、同事等他人态度、没有用户自身愿望时，不替用户补出“想要”，按保守方向投否。

定向复核：

- `他威胁我，但我今晚要不要去见他`：5 / 5 稳定进入议案，三票全否；
- `父母反对，但我还要结婚吗`：5 / 5 稳定为理性否、守护是、自我否，最终否决；
- `周末我想去旅行`：此前问题后定向复测 5 / 5 稳定进入议案并通过。
