# 三相议决 TRIAD

超高智能个人即时决策系统。手机优先的私人终端网页，接入真实 Jev，角色配置 v0.2。

## 启动

需要 Node.js 22 或更新版本，无第三方运行依赖。双击「启动终端.command」，或在本目录运行 `npm start`。保持启动窗口打开。

电脑打开 http://localhost:4317 。手机与电脑连接同一 Wi-Fi，在 Safari 打开启动窗口中显示的局域网网址。若无法访问，请检查系统防火墙与 Wi-Fi 客户端隔离；电脑休眠或停止服务后网页无法提交。当前为本地原型，没有发布公共网址。

## 密钥

本机 `.env.local` 仅指向原有密钥文件，密钥没有复制到项目。迁移项目到其他电脑时，参考 `.env.example` 配置 `TYPESAFE_KEY_FILE`，或在服务端环境设置 `TYPESAFE_API_KEY`。不要把密钥放进 public/。

## 规则

同一 Jev 模型分别评估理性、守护和自我。概率大于 0.5 投是，否则投否，至少两票是即通过。无暂缓票。缺失或异常响应不会计票。服务端只向浏览器返回票型和裁决，不返回概率、角色指令或密钥。

模型输入同时包含一个议案入口分类（Choice），把输入分成议案、感受、多选项、知识、自我价值、危机、伤害他人与指代不明八类；只有「议案」进入投票，其余类别直接返回各自的入口状态，不会成为额外投票。入口属于模型分类，不能保证识别所有情形。

服务端还会随议案附带提交时的本地时间（日期、星期、时段），供角色评估现实得失与安全风险（如“现在去看海吗”）。时间由终端实时生成，不来自用户输入。

## 隐私与部署范围

用户输入会发送到 TypeSafe 供判断。本项目不保存议案历史，不记录输入或原始返回值；内存中仅保留短时限流时间戳。未引入第三方字体、统计脚本或追踪资源。界面使用随项目携带的本地字体子集 `public/eva-ming-sc-subset-v2.woff2`（Eva Ming SC，覆盖界面文字与 GB2312 一、二级字库共 6763 字）。如需重建：重新获取原始字体 Eva Ming SC 后，`pip install fonttools brotli` 并用 `pyftsubset` 按根目录的 `subset-chars.txt`、`common-chars.txt`、`common-chars-2.txt` 字符清单子集化，产物改名带版本号以避开不可变缓存。

当前服务绑定局域网以便手机体验；配有基本的请求大小检查、同源检查和限流。公开发布前需配置 HTTPS、平台级限流与用量控制。无需数据库。

## 文件

- public/：界面、交互、图标与本地字体子集。sound.js 只提供未来音效适配入口，没有实际音频或开关。
- roles.json：测试确定的三个角色配置。
- decision.mjs：议案入口分类、结果校验与多数计票。
- server.mjs：静态页面与官方 Jev 接口连接。
- test/：计票与异常结果验证；运行 `npm test`。

## 视觉与适配

黑褐屏幕、琥珀色、轻度 CRT、三角切角窗口。以 440 CSS px 宽的大屏 iPhone 竖屏为首要设计视口，同时适配更窄手机及桌面。使用安全区内边距及 reduced-motion 支持；实际 Safari 地址栏与字体渲染仍以真机体验为准。
